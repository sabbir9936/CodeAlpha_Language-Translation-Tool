# 🌐 Language Translation Tool

An interactive and responsive web-based **Language Translation Tool** built as part of my internship at **CodeAlpha**. This project allows users to seamlessly translate text between multiple languages, listen to audio pronunciations, and easily copy translations to the clipboard.

---

## 📌 Project Overview
- **Organization:** CodeAlpha
- **Role:** Artificial Intelligence Intern
- **Task:** Task 1 – Language Translation Tool

---

## ✨ Features
- 🔄 **Real-time Language Translation:** Translate text quickly across multiple global languages.
- 🔀 **Language Swap:** Instant swap option between source and target languages.
- 🔊 **Text-to-Speech (Audio Output):** Listen to the output text using built-in speech synthesis.
- 📋 **One-Click Copy:** Easily copy translated output to the clipboard.
- 📱 **Fully Responsive UI:** Clean and modern interface designed using HTML and CSS.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **APIs Used:** 
  - Translation API (MyMemory / Google / Microsoft)
  - Web Speech API (for Text-to-Speech)
